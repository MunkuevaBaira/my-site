# Личное портфолио — Мункуева Баира

Добро пожаловать в репозиторий моего личного сайта-портфолио! Проект представляет собой современный адаптивный сайт, созданный с нуля на чистых HTML, CSS и JavaScript.

## 🔗 Ссылка на опубликованный сайт
Посмотреть сайт вживую можно по этой ссылке (хостинг Netlify):
👉 **[https://munkuevabaira.netlify.app]** 

## 🛠️ Используемые технологии
* **HTML5** — семантическая и доступная верстка.
* **CSS3** — Flexbox, Grid, CSS-переменные (для тем), адаптивность под мобильные устройства, анимации.
* **JavaScript (Vanilla)** — интерактивность, работа с DOM, LocalStorage, отправка данных без перезагрузки страницы (AJAX/Fetch).

## ✨ Ключевые особенности проекта

### Основной функционал:
* **Адаптивный дизайн** — сайт корректно отображается на компьютерах, планшетах и смартфонах.
* **Темная тема** — переключение цветовой схемы сайта одной кнопкой.
* **Рабочая форма обратной связи** — сообщения отправляются напрямую на мою электронную почту через сервис FormSubmit (без перезагрузки страницы).
* **Портфолио** — карточки с моими проектами (включая интерактивный макет ветеринарной клиники в Figma).
* **Кнопка «Наверх»** — плавная прокрутка страницы.

### Режим для слабовидящих (Accessibility):
На сайте реализована специальная выдвижная панель, включающая:
* Изменение размера шрифта.
* Выбор контрастных цветовых схем (черно-белая, синяя и т.д.).
* Возможность скрыть все изображения.
* **Озвучивание текста** (Web Speech API) — при наведении курсора на текст, браузер зачитывает его вслух.
